About This Project

AI Crop Decision Assistant is an MCA academic project that helps a farmer decide which crop to grow based on their land, soil, water, season, budget and location, using machine learning trained on agricultural data.

SDG Alignment

This project supports UN Sustainable Development Goal 2 - Zero Hunger, by helping farmers make more informed, data-driven decisions that can improve yield and income.

Technology Used

  • Python, Flask (backend)
  • Scikit-learn - Random Forest Classifier & Regressor (machine learning)
  • Pandas, NumPy (data processing)
  • HTML, CSS, JavaScript, Chart.js (frontend)
  • SQLite-ready structure / CSV dataset (data storage)

Disclaimer

Predictions are estimates based on historical/sample data and should be validated with local agricultural experts and current market conditions before making real farming decisions. This project does not guarantee profit or yield outcomes.
